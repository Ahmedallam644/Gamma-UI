Phase 1: The "Gamma" UI & Frontend Animations (React)
To make it look and feel like a high-end AI tool, the frontend needs to be fluid and interactive.

The Framework: React with react-i18next for seamless Arabic/English switching.

The Animations (Framer Motion):

Live Typing: As the AI generates text, use Framer Motion to make each sentence smoothly "fade in and slide up."

Image Reveal: When the text for a section finishes, the 5-image Pexels grid smoothly slides in from the right.

Selection: When a student clicks a photo, a glowing border instantly snaps around it.

The Form: A sleek initial input screen collecting the Topic, Student Names, Supervisor (e.g., Dr. Ahmed Abdelrahman), and Department.

Phase 2: The AI Generation & Fallback Engine (Python/FastAPI)
This is the brain of the operation, built for speed and reliability.

Live Streaming: FastAPI streams the text to the React frontend word-by-word using Server-Sent Events (SSE).

The Ironclad Fallback Loop:

Groq Key 1 -> 2. Groq Key 2 -> 3. OpenRouter Key 1 -> 4. OpenRouter Key 2 -> 5. Gemini -> 6. Rest and Loop.

Real Academic Citations: The AI writes the content, but your Python backend makes a separate, background API call to Crossref or Semantic Scholar to fetch real, verifiable APA references (2021-Present) to append to the end.

Phase 3: The Payment & Quality Control Gate
Authentication: Firebase Auth handles user accounts.

The Upload: After the student picks their Pexels images, the UI asks for payment. They upload the Vodafone Cash/InstaPay receipt via ImgBB or Cloudinary.

The Database: Firestore logs the request as pending_approval and stores the receipt link.

Admin Dashboard: You log in, see the receipt, verify the transfer, and click "Approve." Only then does the student get the download link.

Phase 4: The "Beautiful Document" Factory (The Secret Sauce)
You cannot rely on Python or AI to design the layouts in those images from scratch. You must use Master Templates.

Step 1: Build the Shells. Open Microsoft Word and PowerPoint. Recreate the exact designs from your images.

Put the Faculty of Nursing logo on the Word cover page.

Add the subtle medical icons (stethoscopes, DNA strands, pills) into the corners of the PowerPoint Master Slides.

Set the fonts, colors, and RTL Arabic formatting perfectly. Save these as .dotx (Word Template) and .potx (PowerPoint Template).

Step 2: Python Injection. Use python-docx and python-pptx. Write a script that simply opens your beautiful, locked templates and injects the AI-generated text and the chosen Pexels image URLs directly into the empty placeholder boxes you created.
